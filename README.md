# Nutrition Tracker

A modern, responsive web application for tracking nutrition, analyzing food intake, and achieving health goals with AI-powered recommendations.

## Features

- **AI-Powered Analysis**: Get personalized nutrition recommendations based on your eating patterns
- **Smart Food Recognition**: Instantly identify foods and their nutritional content from photos
- **Progress Tracking**: Visualize your nutrition journey with intuitive charts and insights
- **Community Support**: Connect with other users to share recipes and find motivation

## Technologies Used

- HTML5
- CSS3 (with custom variables and responsive design)
- JavaScript (vanilla, no frameworks)
- Font Awesome for icons
- Google Fonts (Poppins, Inter)

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. No build process or dependencies required!
